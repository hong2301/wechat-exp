## 规划用途

自动化操作微信客户端，核心场景：**发消息**。

与 `my_tools/`（读取解密数据）互补：
- `my_tools/` ← 读（提取 / 查询本地聊天数据）
- `my_automation/` ← 写（自动化操作微信，如发消息）
